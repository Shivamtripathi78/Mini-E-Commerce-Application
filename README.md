# Mini E-Commerce Application

ShopEase is a mini online shopping platform built using Python, Flask, SQLite, HTML, and CSS. It allows users to browse products, manage their shopping cart, place orders, and view order history.

## Features
- Product listing and search.
- Category-based filtering.
- Shopping cart management.
- Quantity updates and price calculation.
- Checkout and order placement.
- Order history.
- SQLite database integration.
- Responsive user interface.

## Technologies
- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## Installation

```bash
git clone https://github.com/Shivamtripathi78/Mini-E-Commerce-Application.git
cd Mini-E-Commerce-Application

python -m venv .venv
python -m pip install -r requirements.txt
python app.py
```

## Database

SQLite automatically creates the database and stores products, orders, and order items.

## Note

This project is designed for learning and demonstration purposes. It does not include real payment processing.
